# claude-todo-demo

This repository contains **Revit Model Slimmer**, a Revit add-in that shrinks and speeds up project files by cleaning unused families, filters, empty views, view templates and worksets, auditing performance hogs and compacting the file.

See [RevitModelSlimmer/README.md](RevitModelSlimmer/README.md) for features, supported Revit versions, build and installation instructions.
