A-001About

Fewer workarounds. More design time.

Parametra is one studio's answer to the repetitive parts of Revit: the tags that never line up, the planting that has to be placed twice, the sheets that take an afternoon to renumber.

Everything here comes from live projects. The plugins sit on a single BIM Tools tab, the families are built to be flexed, the files are the templates and libraries we actually start from, and the courses explain how each of them was made.

Scatter that reads the site

Surface Scatter fills a floor, toposolid or filled region from your Plant Library at a spacing you set, with jitter so nothing looks stamped. Path Scatter follows a model line, and Edit Scatter re-flows the set when the boundary moves.

Shadows before the meeting

Shadow Analysis reads the project location and the sun settings you already have, then reports shaded area per surface. Shadow Links keeps those results tied to the elements, so the schedule updates when the massing does.

Sheets that line themselves up

Align Tags, Align Elements, Align Viewports and Align Railing share one idea: select, pick an edge, done. Manage Viewports and Manage Legends keep whole sheet sets consistent.

F-200Parametric families

Families that flex instead of break.

Every family in the library is built the same way: shared parameters, formulas that guard against impossible values, and a type catalog so the office standard sizes are one click away. Drag the sliders and watch the geometry, the schedule values and the material take-off follow.

Type catalogs, not type soup

Standard sizes ship as a catalog, so a project loads only the types it needs and the family stays light. Custom sizes are one instance parameter away and never break the standard ones.

Formulas that refuse to fail

Rafter count, post spacing and member sizes are derived, not typed. Push a dimension too far and the family clamps it instead of throwing a constraint error at the person who least expects it.

Scheduled from day one

Shared parameters mean the pergola volume, the planter soil quantity and the bench seat length all land in schedules without a mapping exercise.
